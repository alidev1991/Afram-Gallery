# ARFAM Gallery

Luxury digital gallery and e-commerce project built with Next.js, React,
TypeScript, and Tailwind CSS.

## Requirements

- Node.js 20.9 or newer
- npm

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Database

The database foundation uses Prisma with SQLite. See
[`prisma/README.md`](prisma/README.md) for local setup, migrations, deployment,
and seed conventions.
