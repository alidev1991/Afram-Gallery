# ARFAM Gallery

Luxury digital gallery and e-commerce project built with Next.js, React,
TypeScript, and Tailwind CSS.

## Requirements

- Node.js 20.9 or newer
- npm

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Current scope

Phase 2 establishes only the technical foundation. Database, authentication,
storefront design, cart, checkout, orders, and admin features belong to later
phases.
